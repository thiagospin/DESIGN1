Utilize o CSS para transformar os conteúdos em cartões de cursos com uma identidade visual consistente.

- [ ] Criar um fundo para cada cartão.

- [ ] Definir uma largura e um espaçamento interno iguais para todos.

- [ ] Aplicar a mesma cor e o mesmo tamanho aos títulos dos cursos.

- [ ] Criar botões com a mesma cor, o mesmo espaçamento e o mesmo alinhamento.

- [ ] Arredondar os cantos de todos os cartões da mesma maneira.

Regra do exercício: os alunos devem utilizar as classes .curso e .botao para aplicar estilos comuns aos três cartões, evitando criar regras CSS diferentes para cada curso.
