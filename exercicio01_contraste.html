SAIBA MAIS

O cartaz apresenta pouca diferenciação entre seus elementos. A tarefa é modificar somente o CSS para tornar a composição mais interessante e facilitar a identificação das informações importantes.

Tente realizar as seguintes alterações:

- [ ] Contraste de cores: destacar o título com uma cor escura e utilizar uma cor vibrante para a data.

- [ ] Contraste de tamanho: aumentar o título e deixar as informações secundárias menores.

- [ ] Contraste tipográfico: utilizar negrito no título e na data, mantendo o texto descritivo com peso normal.

- [ ] Contraste entre elementos: fazer o botão “SAIBA MAIS” se destacar do fundo.

- [ ] Legibilidade: garantir que todos os textos sejam fáceis de ler.
